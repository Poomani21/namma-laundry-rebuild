# Namma Laundry Rebuild

Rebuild ONLY the Namma Laundry Home page using my attached reference image as the EXACT design.

Do NOT create a similar design or add your own ideas. Match the reference as closely as possible — same layout, sections, text, colors, typography, spacing, cards, icons, images, buttons, hero composition, and overall proportions.

Remove all existing Home page content that is not in the reference.

Keep the existing logo, header, navigation, Firebase, admin panel, pricing/services data, routes, and all other pages unchanged.

Use existing project assets/data wherever applicable. Keep all existing buttons and links functional.

Desktop and mobile must both follow the reference composition. No horizontal scrolling.

The final result should look like the reference image, NOT like the current Home page and NOT like a generic laundry website.

Do not modify anything outside the Home page.
